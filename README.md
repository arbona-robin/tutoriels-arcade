# Tutoriels MakeCode Arcade

Tutoriels en français pour le parcours Maker Junior, et extension pour jouer avec une manette micro:bit.

| Tutoriel | Lien |
|---|---|
| Jeu de plateforme | https://arcade.makecode.com/?lang=fr#tutorial:https://github.com/arbona-robin/tutoriels-arcade/plateforme |

## Extension manette

Dans MakeCode Arcade, **Extensions**, puis colle l'adresse de ce dépôt :

```
https://github.com/arbona-robin/tutoriels-arcade
```

Les blocs **Manette** apparaissent dans la boîte à outils. La page relais transmet au jeu les mots envoyés par le micro:bit, et renvoie au micro:bit les réactions demandées par le jeu.
